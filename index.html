Model and interpretation

Total genome length is adjustable from 200 to 2,000 bp and stays fixed when repeat settings change. Identical, directly oriented copies of one repeat are separated by evenly sized blocks of single-copy genomic DNA. At least 20 bp of background are retained in every block; repeat-copy choices are limited to what fits. With zero copies, all DNA is single-copy genomic DNA. Short accidental sequence matches can still occur in random DNA.

Fragments are sampled uniformly, with replacement, among valid start positions. Each fragment is sequenced in full without errors, in a common forward orientation. Read length is capped at genome length. The read count is rounded up from target depth × genome length / read length; actual depth is reported. Linear ends have lower expected coverage. This is not paired-end sequencing.

The assembler receives only sequence strings. It removes duplicate and contained strings, finds exact suffix–prefix overlaps, and repeatedly merges the longest overlap that is the unique best choice for both participating ends. Ties remain unresolved. Containment is checked again after each join. Read coloring uses true origin only for teaching: purple reads lie entirely within one inserted repeat and have no unique flank. They remain in the assembly input and coverage counts; with identical repeat copies, they cannot determine copy identity. Reverse greedy instead seeds the longest merged read pair and extends by the greatest number of new bases at either end. Contained reads are omitted from its construction path. Ties are resolved by larger overlap, then stable read order; it does not promise a globally minimum path or a correct assembly. Both strategies use only sequences. This teaching heuristic can stop at branches, collapse repeat copies, or create an incorrect join; it is not a production assembler and stopping does not prove that every remaining join is impossible.

Only after assembly, each entire contig is searched against the reference. All exact placements are shown, including multiple placements. A contig with no complete exact match is flagged as an incorrect assembly. Reference coverage by exact contig placements is not proof of copy-number recovery: one repeat-only contig can map to several copies. A correct complete reconstruction requires a single contig equal to the entire original genome.
